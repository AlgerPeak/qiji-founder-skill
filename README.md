# 早期商业化诊断 Skill

一个给技术创始人的早期商业化诊断工具。装上之后，你可以直接问它「帮我看下商业化」「客户聊了就是不签」「这个价格怎么定」，它会先要几个真实数字，判断你卡在哪一步，最后给你一张诊断卡和这周要做的一件事。

内容整理自奇绩创坛 COO 栾运明（Max）给奇绩录取创始人的内部分享。

## 它跟别的方法论有什么不一样

市面上的商业化方法论大多停在讲框架。这个 skill 的第一步是先问你要四个数字，这个月聊过几个客户、收过钱没有、最近三个没签的单子卡在哪、价格是怎么定的。

答不上来，本身就是结果。你连这个月聊过几个客户都说不出来，问题就不在销售技巧，而在客户接触量。

数字拿到之后，它会告诉你卡在哪一步，然后只给一件这周能做的事。最后产出一张可以存下来的诊断卡。

## 它能诊断什么

**找客户。** 第一批对话从哪里来，内容和外联怎么配合，渠道什么时候能用。

**需求验证。** 客户说挺好但不动，到底是哪里不对。

**谈单。** 用 BANT 和客户采购作战地图，把「应该能成」拆成具体是预算、决策权、需求还是时间断了。

**定价。** 按价值定价怎么算，四种测价格的方法。

**市场选择。** 怎么从十个可能市场里切出一个能赢的。

**心态。** 总想再打磨打磨、不好意思收钱，这一层单独处理。

还包含三个常被问到的判断题，客户给的非核心需求要不要接、什么时候招第一个销售、单子聊不动了怎么办。

## 怎么装

把 `skills/early-commercialization` 整个文件夹复制到你的 skills 目录。

```bash
git clone https://github.com/AlgerPeak/qiji-founder-skill.git
cp -r qiji-founder-skill/skills/early-commercialization ~/.claude/skills/
```

Windows 用户放到这里。

```
C:\Users\<你的用户名>\.claude\skills\
```

## 怎么用

装好之后直接说你的问题，不用记命令。

「我产品做出来了，但没人付钱，帮我看看卡在哪。」

「有个客户聊了两个月一直不签，是不是该放弃。」

「我这个产品定价多少合适。」

「有个客户想要的东西不是我们的主线，要不要接。」

## 一次真实对话长什么样

**你**：帮我看看商业化，我的东西做出来了，但一直没收到钱。

**它**：先问你一个数字，这个月你和多少个潜在客户正经聊过。注意是聊，不是加微信、不是发资料。

**你**：得有二十来个吧，加了微信发过资料。

**它**：那再确认一下，坐下来正经聊过需求的有几个。

**你**：三个。

**它**：三个的话，问题不在销售技巧，在接触量。你现在的样本还不足以判断产品行不行。这周先把接触量提到十个，方法有两个。一是直接外联，前十个客户你自己谈，别交给别人。二是把产品拍出来发出去，让人主动找你。

然后它会给你一张诊断卡：

```
商业化诊断卡
现状：这个月正经聊过 3 个客户，未收到付款
判断：卡在找客户，样本量不足，无法判断需求真假
本周一件事：把接触量提到 10 个，全部由创始人本人谈
下次检查：如果十个聊完仍无人愿意进入下一步，判断改为卡在需求验证
```

## 说明

这个 skill 会追问模糊的说法，这是它最有用的动作。它不会一次给你五条建议，也不会夸你。它只做梳理、提问和判断，不替你做决定。

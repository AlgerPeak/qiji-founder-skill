# 技术创始人早期商业化陪跑 Skill

一个给技术创始人的早期商业化自检工具。装上之后，你可以直接问它「帮我看下商业化」「第一笔钱怎么来」「这个价格怎么定」，它会先判断你卡在哪一步，再给一到两个具体动作。

内容整理自奇绩创坛合伙人栾运明（Max）给奇绩录取创始人的内部分享。

## 它解决什么问题

技术创始人的卡点通常不在产品，而在没人愿意掏钱。这个 skill 把早期商业化拆成四层。

**找客户**。第一批对话从哪里来，内容和外联怎么配合。

**谈单**。一个单子值不值得投入，谁决策、谁买单、什么时候落地。

**定价**。按价值定价怎么算，价格怎么测。

**找规律**。市场怎么切到能赢，客户怎么从零散变稳定。

里面收了 BANT、客户采购作战地图、价格敏感度测试、七二一资源分配、招销售的三个信号，以及一份自检清单。

## 怎么装

### 方式一，复制到 skills 目录

把 `skills/early-commercialization` 整个文件夹复制到你的 skills 目录。

```bash
git clone https://github.com/<你的用户名>/qiji-founder-skill.git
cp -r qiji-founder-skill/skills/early-commercialization ~/.claude/skills/
```

Windows 用户把这个文件夹放进去。

```
C:\Users\<你的用户名>\.claude\skills\
```

### 方式二，作为插件安装

在 Claude Code 里执行。

```
/plugin marketplace add <你的用户名>/qiji-founder-skill
```

## 怎么用

装好之后，直接说你的问题就行，不用记命令。

「我产品做出来了，但没人付钱，帮我看看卡在哪。」

「有个客户聊了两个月，一直不签，是不是该放弃。」

「我这个产品定价多少合适。」

## 例子

问：第一批客户到底从哪里来。

它会先反问你三个问题。有没有目标客户名单，名单怎么来的。有没有在持续做内容，发了多少条。有没有满意的客户，问过对方能不能介绍同类。

然后根据你的回答给动作。如果你还没做过内容，它会建议你从手边能拍、能写的东西开始，并且强调量比精美更重要，因为转化的比例是有限的，发十条和发一百条结果完全不同。

## 说明

这个 skill 只做梳理和提问，不替你做决定。它不会一次给你五条建议，每次只给最重要的一两条，并且要求你对话结束时手里有一件具体要做的事。
